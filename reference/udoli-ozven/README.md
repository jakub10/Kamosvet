# Údolí ozvěn — Jakubův svět

Jakubův první pokus o Kamosvět: hotové 3D údolí v Three.js (jeden soubor,
1 600 řádků). Nekonečný terén po dlaždicích, meandrující řeka, plavání,
den a noc se slunkem, měsícem a hvězdami, lišky, a pojmenovaná místa:
Větrná věž, Kamenný most, Tábor pod javorem, Modrý krystal, Květ ozvěny.

Uložený tady jako **reference**, ne jako kód, který se spouští. Kamosvět
stojí na DreamWorldu (pravidlo: svět je Nicota, která se probouzí tam,
kde dítě chodí). Jakubův slovník — řeka, věž, most, tábor, krystal,
lišky — je to, **na co se růst promění** v pozdějších fázích, a co po
sobě nechá společný quest dvou kamarádů. Nic z toho se nezahazuje;
Jakub navrhuje, co se objeví.
